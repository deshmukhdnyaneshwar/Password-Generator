# 🔐 Password Generator

A simple and interactive **Password Generator** built using HTML, CSS, and JavaScript.

This project generates random and secure passwords based on the user's selected requirements such as password length, uppercase letters, lowercase letters, numbers, and special characters.

## 🚀 Features

* 🔑 Generate random passwords
* 🔢 Select password length
* 🔠 Include uppercase letters
* 🔡 Include lowercase letters
* 🔢 Include numbers
* 🔣 Include special characters
* 📋 Copy generated password
* ⚡ Generate passwords instantly
* 📱 Responsive design
* 🎨 Simple and user-friendly interface

## ⚙️ How It Works

The Password Generator uses JavaScript to create a random password based on the options selected by the user.

### Password Generation Process

1. User selects the required password length.
2. User selects the character types to include.
3. JavaScript creates a character set based on the selected options.
4. Random characters are selected from the character set.
5. The generated password is displayed on the screen.
6. The user can copy the password to the clipboard.
